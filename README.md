# 💰 Personal Finance Tracker with AI-Based Spending Insights

A full-stack web application that helps users manage their personal finances by tracking expenses, setting budgets, analyzing spending patterns, and generating AI-based financial insights.

---

## 🚀 Features

* 🔐 User Authentication (Login & Register)
* ➕ Add and Manage Expenses
* 📊 Dashboard Analytics with Pie Chart
* 💡 AI-Based Spending Insights
* 💰 Budget Tracking with Alerts
* 📄 Export Reports as PDF & CSV
* 🌙 Dark Mode Support
* 📱 Responsive UI Design
* 🎨 Modern Landing Page with Animations

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/finance-tracker.git
```

### 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

### 3️⃣ Start Backend Server

```bash
node server.js
```

### 4️⃣ Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5️⃣ Start Frontend

```bash
npm start
```

---

## 🌐 Environment Variables

Create a `.env` file inside the `backend` folder and add:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
